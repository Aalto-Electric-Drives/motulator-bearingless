# Finite-element model and gradient networks

This folder contains the FEMM model of the 2.6-kW six-phase bearingless synchronous reluctance machine, the generation of the dataset, and the training of the gradient networks. The results are in `examples/datasets/` and `examples/trained_models/`, and they are used by the examples. The scripts need [femm-qt](https://github.com/dcm3c/femm-qt), the cross-platform FEMM 5.0, and its Python interface in the same environment, installed from the femm-qt checkout with `pip install -e pyfemm` (not the `pyfemm` package of FEMM 4.2), as well as the optional dependencies, `pip install -e .[fem]`. The Python interface finds `femm_headless` in the build directory of the checkout, in the directory given by `FEMM_DIR`, or on `PATH`.

## Machine

The rated values and the stator resistance are from Das et al. (ICEM 2026). Nothing has been calibrated to measurements.

| Quantity                            | Value                                                                              |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| Stator                              | 36 slots, inner radius 72.5 mm, outer radius 117.5 mm                              |
| Winding                             | Single layer, 16 conductors per slot, 48 series turns per phase                    |
| Phases                              | Six coil groups spanning 90 deg, with the magnetic axes at 60 deg intervals        |
| Rotor                               | Four poles, four streamline flux barriers per pole, 1.5-mm ribs                    |
| Air gap, stack length, shaft radius | 1 mm, 195.25 mm, 27 mm                                                             |
| Steel                               | Tables of `bsyrm_femm.py`, lamination fill factors 0.975 (stator) and 0.98 (rotor) |

The end-winding leakage, the skew, the axial end effects, and the losses are not included. The solid shaft is treated as magnetostatic.

## Conventions

The conventions are those of Ahmed et al. (ECCE 2023) and Das et al. (ICEM 2026), see the docstring of `bsyrm_femm.py`:

- The winding function of phase k has its maxima at `(k - 1)*60` deg, for both the two-pole and four-pole components.
- The rotor angle `theta_M` is the angle of the d-axis (no barriers) from the axis of phase 1.
- Peak-valued space vectors of the planes h = 1 and h = 2 in rotor coordinates, `i_s1 = exp(-1j*theta_M)*i_s1_ab` and `i_s2 = exp(-2j*theta_M)*i_s2_ab`. Hence, `i_s1d` and `i_s2d` together give a positive force along the i-axis at `theta_M = 0`.
- The displacement `q_M` is the position of the rotor center relative to the center of the stator bore. In FEMM, the rotor center stays at the origin and the stator moves by `-q_M`, so that the torque integral refers to the rotor center.

## Boundary conditions

A = 0 on the outer surface of the stator. This is the only outer boundary, since the whole cross-section is modeled and the shaft is a meshed part of the rotor (solid steel). The two-pole flux crosses the center of the rotor, so that the shaft is not a boundary of the field, unlike in one-pole models of machines without radial force. A = 0 on the shaft surface and a nonmagnetic shaft are available for comparison (`Params.shaft`).

## Dataset

The energy function depends on seven variables, so a tensor grid is out of the question. `sample_plan.py` creates the points:

- Set 0: 16384 training points from a Sobol sequence, denser at small two-pole currents and displacements. The ranges are `|i_s1| <= 15 A`, `|i_s2| <= 36 A` (the rated peak current is 17 A), `|q_M| <= 400 µm`, and `0 <= theta_M < 60 deg`.
- Set 1: 1024 test points from another Sobol sequence in the same ranges, spread more widely. They are not used in the training.
- Sets 2-5: structured slices for validation and plots, not used in the training.
- Set 6: 4096 additional training points in the normal operating range, `|i_s1| <= 3 A`, `|i_s2| <= 26 A`, and `|q_M| <= 100 µm`.
- Set 7: 1024 additional training points around no load, as set 6 but with `0 <= i_s2q <= 4 A`, since the two-pole inductance and the force constant change quickly with `i_s2q` there.

More points can be appended to the plan: `run_maps.py` skips the points already solved. The meshes have about 60 000 elements. Compared with about 730 000 elements, the differences in the checked points are at most 2.7 mVs in the flux linkages and 0.8 % in the force.

## Symmetries

For a four-pole rotor in a symmetrical six-phase stator without zero-sequence currents, the energy function in rotor coordinates is periodic in `theta_M` with the period of 60 deg and invariant under the group of 16 elements generated by:

- `(-i_s1, -i_s2, q_M, theta_M)`
- `(conj(i_s1), conj(i_s2), conj(q_M), -theta_M)`
- `(-1j*i_s1, -i_s2, -1j*q_M, theta_M + 30 deg)`

The networks are symmetrized over this group. One finite-element point thus informs 16 points of the input space, and the force and the two-pole flux linkage vanish exactly at `i_s1 = 0`, `q_M = 0`. The same symmetries hold for the energy as a function of the flux linkages.

## Networks

The architecture of the networks is that of *motulator*: one softmax gradient network, see `docs/source/gradnet.md`. The machine model uses energy-based current maps and the controller a co-energy-based flux map:

| File in `examples/trained_models/`         | Map                        | Hidden units | Periodic features `k` |
| ------------------------------------------ | -------------------------- | ------------ | --------------------- |
| `bsyrm_fem_curr_map_harm_softmax_d128.npz` | Current map with harmonics | 128          | 6, 36                 |
| `bsyrm_fem_curr_map_softmax_d64.npz`       | Current map                | 64           |                       |
| `bsyrm_fem_flux_map_softmax_d128.npz`      | Flux map                   | 128          |                       |

At the nine points checked by central differences (`check_model.py hessian`), the Hessian of the co-energy is symmetric within the relative error of 1.2e-4 and positive definite, i.e., the co-energy is jointly convex in the currents and the displacement. The stiffness of the unbalanced magnetic pull at constant flux linkages is positive at these points, from 0.02 N/µm to 4.7 N/µm, so that the energy is locally concave in the displacement. The current maps use `k_q` = 10 N/µm. According to the flux map, it exceeds the largest eigenvalue of the stiffness matrix of the pull at constant currents at 99.9 % of the data points, and the exceptions are at displacements above 160 µm. The networks without the rotor angle are trained on the same data, so that they approximate the average over the rotor angle. The period of the maps is 60 deg, so `k = 6` is the fundamental order. The second pair `k = 36` is added, since the slot harmonics of the 36-slot stator dominate the torque ripple. It decreases the torque error of the normal operating range from 0.27 Nm to 0.18 Nm.

The RMS errors on the held-out test points are given below, for all the points and for those in the normal operating range, `|i_s1| < 3 A`, `|i_s2| < 26 A`, and `|q_M| < 100 µm`. The errors of the models without the rotor angle include the variation over the angle.

| Map                        | Points | `i_s1` or `psi_s1` | `i_s2` or `psi_s2` | `f_M` | `tau_M` |
| -------------------------- | ------ | ------------------ | ------------------ | ----- | ------- |
| Current map with harmonics | All    | 105 mA             | 151 mA             | 59 N  | 0.37 Nm |
|                            | Normal | 40 mA              | 97 mA              | 15 N  | 0.18 Nm |
| Current map                | All    | 366 mA             | 384 mA             | 159 N | 1.6 Nm  |
|                            | Normal | 80 mA              | 195 mA             | 27 N  | 0.76 Nm |
| Flux map                   | All    | 7.6 mVs            | 3.7 mVs            | 198 N | 1.5 Nm  |
|                            | Normal | 2.3 mVs            | 2.3 mVs            | 32 N  | 0.69 Nm |

The mean of the force error over the rotor angle at `|i_s1| <= 2 A` is below 2 % for the current maps and about 3 % for the flux map.

## Usage

```bash
python sample_plan.py plan.npz
python run_maps.py plan.npz results.txt 7          # Continues an interrupted run
python make_dataset.py plan.npz results.txt ../examples/datasets/bsyrm_fem.npz
python check_model.py boundary mesh symmetry hessian field field.png

M=../examples/trained_models
D=../examples/datasets/bsyrm_fem.npz
python train_gradnet.py $D $M/bsyrm_fem_curr_map_harm_softmax_d128.npz --map current --embed 128 --k 6 36 --seed 4
python train_gradnet.py $D $M/bsyrm_fem_curr_map_softmax_d64.npz --map current --embed 64
python train_gradnet.py $D $M/bsyrm_fem_flux_map_softmax_d128.npz --map flux --embed 128 --s_2 0.007
python evaluate_gradnet.py $D $M/bsyrm_fem_curr_map_harm_softmax_d128.npz
python compare_control.py results.json
```

The temporary files of FEMM go to `/dev/shm/bsyrm_femm` (or set `BSYRM_FEMM_WORK`).

| File                                               | Contents                                                          |
| -------------------------------------------------- | ----------------------------------------------------------------- |
| `bsyrm_femm.py`                                    | Parametric geometry, materials, winding, and the solver interface |
| `sample_plan.py`, `run_maps.py`, `make_dataset.py` | Dataset                                                           |
| `check_model.py`, `field_plot.py`                  | Checks of the model and field plots                               |
| `train_gradnet.py`, `evaluate_gradnet.py`          | Training of the networks and their errors                         |
| `compare_control.py`                               | Direct force control with different machine and controller models |
